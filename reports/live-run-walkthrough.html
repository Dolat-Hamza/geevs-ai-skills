What this run showed, and what it didn't

Showed

  • The human made two decisions per task. Everything else ran on its own.
  • Release was refused until the proof ran, for both code and the document.
  • The tests demonstrably caught the bug: they failed before the fix and passed after.
  • A missing source for a figure was caught by name.

Didn't show

  • Real Geevs work: these are small sandbox tasks.
  • A comparison with doing the same tasks in a normal chat.
  • That the figure 1.00 was correct. The 1.2.0 proof accepted it without checking the arithmetic. Fixed in 1.2.1, which now recomputes derived figures.
