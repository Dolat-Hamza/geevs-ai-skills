What working with the agent team looks like

A replay of a real test run on 29 October 2026. You ask for something, approve a short plan, and get back finished work that has already been checked. Click through the steps.

Use a normal chat for quick questions and small edits. Use the agent team when a mistake would be costly: anything client-facing, anything involving money, or work other people will rely on.

Easy to use, easy to change

To use itOne line

Type the request in plain English after the deliver command. The team asks for anything else it needs.

Mid-taskJust say so

Before you approve the plan, tell Claude what to change and it rewrites the checklist. After approval, ask for the change and it goes through the checks again.

The team itselfWritten in plain text

Each team member's role, the checks and the spending limit live in short text files. Ask Claude to change them, for example "make the checker stricter on client documents", and it edits them for you.

Works for more than code

Documents, customer notes and processes go through the same steps as software fixes.

Spending limit per task

Each task has a usage budget. Claude asks before going over it.

Switch it on per project

Turn it on once in a project folder, and off again by removing one file. Other projects are unaffected.
