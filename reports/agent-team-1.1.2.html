Live testing found 9 defects across 1.0.0 and 1.1.1, and all are fixed in 1.1.2. The one gap left is an install-time setting that this Claude Code version may ignore.

How it works

/geevs-agent-team:deliver <goal> interview ─▶ research (0–3 researchers, Haiku) ─▶ spec ─▶ [you approve] ─▶ builder (Sonnet, own worktree) ─▶ reviewer (Sonnet, cannot edit, records evidence) ▲───────── failed criteria, at most 3 reviews ─────────┘ ─▶ release summary ─▶ [you push / merge: the permission rules ask first]

Limits and open items

Known limits

  • Permission rules match command prefixes. They don't stop bash -c, full binary paths or scripts. Use Claude Code sandboxing for a hard boundary.
  • Rules and hooks apply only in clones that ran setup, with Claude Code opened in that folder.
  • Budget is an estimate from published prices, checked before each agent spawn, not mid-agent.

Not verified

  • omitClaudeMd on Claude Code 2.1.267. The docs list 2.1.271 or later.
  • Haiku research quality against Sonnet on real questions.
  • claude plugin eval suites: early access, not enabled on this account.
  • Team use beyond one sandbox. That's the pilot.
