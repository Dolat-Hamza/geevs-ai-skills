Try the agent team yourself

A step-by-step test on a small practice project, so nothing real is touched. You'll install it, then watch it write a customer note and fix a pricing mistake, approving each one along the way.

About 30 minutesincluding reading what it produces
About $1 of usagefor both practice tasks together
Nothing goes outeverything stays on your computer

Before you start

  • The Claude desktop app, with the Code tab.
  • Access to the GitHub repository Dolat-Hamza/geevs-ai-skills. If you're asked to sign in to GitHub during setup, sign in.
  • Optional: to see the usage, type /usage in Claude before and after the test.

Part 1: Install it

once, about 2 minutes
  1. You

    Open the Claude app, go to the Code tab and start a new session. Any folder is fine. Paste this message and send it:

    Please install the agent team plugin by running these two commands: claude plugin marketplace add Dolat-Hamza/geevs-ai-skills and then claude plugin install geevs-agent-team@geevs

    You'll see Claude run the two commands and confirm the plugin is installed. If it asks permission to run them, allow it.

  2. You

    Quit the Claude app completely and open it again. It only picks up new plugins when it starts.

Part 2: Get the practice project

about 3 minutes
  1. You

    In a Code session, paste this:

    Copy the folder examples/practice-project from the GitHub repository Dolat-Hamza/geevs-ai-skills into a new folder on my Desktop called agent-practice. Then make agent-practice its own git repository with one commit.

    You'll see a new agent-practice folder on your Desktop. It's a tiny fee calculator with a price list, and it has a deliberate pricing mistake in it.

  2. You

    Start a new Code session and choose the agent-practice folder as its folder. If you're asked whether to trust the folder, say yes.

    This matters: the team's safety rules only apply when the session is opened inside the project's own folder.

Part 3: Switch it on for this project

a few seconds
  1. You

    In that session, type:

    /geevs-agent-team:setup

    You'll see a short confirmation that the safety rules were added. From now on, in this folder, Claude asks you before pushing, merging, deploying or publishing anything.

Part 4: First task, write a customer note

about 5 to 10 minutes
  1. You

    Type:

    /geevs-agent-team:deliver Write a one-paragraph customer note explaining the minimum fee and rounding rule, with one worked example, citing the README.
  2. Claude

    Claude asks a few questions. Answers that work:

    Who is it for? Retail customers sending money abroad.
    Where should facts come from? Only the README price list.
    What counts as done? Every figure checked against the price list.
  3. Claude

    Claude shows you a plan: a short checklist of what the finished note must do.

    Your decision. Read it. If you want something different, say so in plain words and it updates the plan. When you're happy, reply approved.

  4. Claude team

    One team member writes the note. A separate one checks every statement against the price list, and an automatic check confirms it. This takes a few minutes. You don't need to do anything.

  5. You

    Claude gives you a summary: the finished note, each checklist item with how it was checked, and the cost.

    Try asking "Show me the note" or "How did you check the figures?"

Part 5: Second task, fix the pricing mistake

about 5 to 10 minutes
  1. You

    Type:

    /geevs-agent-team:deliver Transfers of exactly 1,000 and exactly 10,000 GBP are charged the wrong fee. Fix it so the fees match the pricing table in the README.
  2. Claude

    Answer its questions. For example: it's used by our own systems, use no new tools, and done means the fees match the price list and all existing checks pass. Then read the plan and reply approved.

  3. Claude team

    The fix is made on a separate copy. The team then proves it: new checks fail on the old version, showing they catch the mistake, and pass on the fixed one.

  4. You

    What to look for in the summary: £1,000 should now cost £5.00 instead of £10.00, and £10,000 should cost £25.00 instead of £50.00.

Part 6: Try something of your own

Once the two practice tasks make sense, try a real but low-risk task. Use a copy of a project folder, not the original. Repeat Part 3 in that folder first, then type /geevs-agent-team:deliver followed by what you want, in your own words.

Part 7: Use it in a normal chat too

about 5 minutes to set up

The same process works in an ordinary Claude chat, which is handy for documents, figures and checked answers. Set it up once:

  1. You

    In a Code session, paste this to get the chat version onto your Desktop:

    Copy the file chat/agent-team.zip from the GitHub repository Dolat-Hamza/geevs-ai-skills to my Desktop.
  2. You

    In Claude, open Settings → Capabilities → Skills, choose Upload skill, and pick agent-team.zip from your Desktop.

    If you don't see Skills there, it may need switching on for your account. Ask whoever manages your Claude workspace.

  3. You

    Start a new chat. Begin your message with "Use the agent team:", then paste or attach what it should work from. For example:

    Use the agent team: write a short FAQ answer explaining our minimum fee and rounding, with a worked example for a 250.50 GBP transfer. Here is our price list: under 1,000 GBP is 1.0%, 1,000 to under 10,000 is 0.5%, 10,000 and above is 0.25%. Minimum fee 2.00 GBP. Fees round half-up to 2 decimals.

    You'll see the same flow: a few questions, a checklist to approve, then the answer with a check table showing every figure and where it came from. In our test, the fee came out at 2.51 GBP, correctly rounded.

Removing it

To remove the chat version, delete agent-team under Settings → Capabilities → Skills. To uninstall the Code version, paste this into a Code session, then restart the app:

Please run: claude plugin uninstall geevs-agent-team@geevs

The practice folder on your Desktop can simply be deleted.
